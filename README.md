# Product Catalog

Учебный каталог товаров на Flutter для Android, iOS и браузера. Данные приходят с [DummyJSON](https://dummyjson.com/docs/products). В каталоге можно открыть товар и посмотреть фото, цену со скидкой, рейтинг, остаток и описание.

## Запуск

В папке проекта:

```powershell
flutter pub get
flutter run -d edge
```

Для Android запусти эмулятор или подключи телефон с отладкой по USB. Узнай его идентификатор через `flutter devices` и запусти `flutter run -d ИДЕНТИФИКАТОР`. Для запуска на iOS нужен Mac с Xcode. Для каталога нужен интернет.

## Что показать на защите

1. Открыть каталог. Приложение отправляет `GET https://dummyjson.com/products` и показывает список из ответа.
2. Нажать на товар, показать его данные и вернуться назад.
3. Показать `lib/product_bloc.dart`. Событие `LoadProducts` запускает запрос. BLoC выдаёт состояние загрузки, результата или ошибки. `BlocBuilder` перестраивает экран при изменении состояния.
4. Показать публичный репозиторий на GitHub.

## Классы и методы

### `lib/main.dart`

| Код | Что делает |
| --- | --- |
| `main()` | Запускает приложение через `runApp`. |
| `CatalogApp()` | Создаёт корневой виджет. |
| `CatalogApp.build()` | Настраивает тему и главный экран. `BlocProvider` создаёт BLoC и отправляет первое событие загрузки. |
| `CatalogPage()` | Создаёт экран каталога. |
| `CatalogPage.build()` | Показывает индикатор, ошибку с кнопкой повтора, пустой список или товары. Нажатие на строку открывает детали. |
| `ProductPage(product: ...)` | Принимает выбранный товар. |
| `ProductPage.build()` | Показывает данные товара. Стандартная стрелка Flutter возвращает к списку. |
| `ProductImage(url: ..., size: ...)` | Принимает адрес картинки и размер. |
| `ProductImage.build()` | Загружает картинку по URL. Если загрузка картинки не удалась, показывает иконку. |

### `lib/product.dart` и `lib/product_api.dart`

| Код | Что делает |
| --- | --- |
| `Product(...)` | Хранит данные одного товара. |
| `Product.fromJson()` | Создаёт товар из полей JSON. `toDouble()` позволяет прочитать цену и другие числа, даже если сервер прислал целое число. |
| `Product.salePrice` | Вычисляет цену с учётом процента скидки. |
| `ProductApi()` | Создаёт объект для запросов к серверу. |
| `ProductApi.getProducts()` | Отправляет GET, ждёт ответ до 15 секунд и превращает JSON в список `Product`. При проблеме с запросом или ответом передаёт ошибку в BLoC. |

### `lib/product_bloc.dart`

| Код | Что делает |
| --- | --- |
| `LoadProducts()` | Событие «загрузить товары». У него нет полей, потому что запрос всегда один и тот же. |
| `ProductStatus` | Перечисляет три состояния экрана: `loading`, `ready` и `error`. |
| `ProductState(status, [products])` | Хранит статус и список товаров. По умолчанию список пуст. |
| `ProductBloc(api)` | Получает API, задаёт начальное состояние и связывает событие с обработчиком. |
| `ProductBloc._loadProducts()` | Выдаёт состояние загрузки, вызывает API, затем выдаёт список или ошибку. |
