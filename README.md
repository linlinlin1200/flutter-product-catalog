# Circuit

Учебный каталог техники на Flutter для Android, iOS и браузера. Товары, цены и фото приходят с [DummyJSON](https://dummyjson.com/docs/products). В каталоге есть ноутбуки, смартфоны, планшеты и аксессуары.

## Запуск

В папке проекта выполни:

```powershell
flutter pub get
flutter run -d chrome
```

Для Android запусти эмулятор или подключи телефон с отладкой по USB. Узнай идентификатор через `flutter devices` и запусти `flutter run -d ИДЕНТИФИКАТОР`. Для iOS нужен Mac с Xcode. Для загрузки товаров нужен интернет.

## Что показать на защите

1. Открыть каталог. По умолчанию видны ноутбуки, отсортированные от самых дешёвых.
2. Перейти в раздел смартфонов и выбрать сортировку по рейтингу. Список обновится сразу.
3. Открыть карточку и показать фото, цену со скидкой, прежнюю цену, рейтинг, остаток и описание.
4. Показать в коде, как `ProductApi` получает товары, а `ProductBloc` переключает категорию и сортировку. Затем открыть публичный репозиторий.

## Классы и методы

### `lib/main.dart`

| Код | Что делает |
| --- | --- |
| `main()` | Запускает приложение через `runApp`. |
| `CatalogApp()` | Создаёт корневой виджет. |
| `CatalogApp.build()` | Настраивает тему. `BlocProvider` создаёт BLoC и отправляет первое событие загрузки. |
| `CatalogPage()` | Создаёт экран каталога. |
| `CatalogPage.build()` | Показывает индикатор, ошибку с кнопкой повтора или каталог. В каталоге выбирают раздел и сортировку, а число колонок зависит от ширины окна. |

### `lib/product_widgets.dart`

| Код | Что делает |
| --- | --- |
| `CatalogHero(product: ...)` | Принимает первый товар текущего раздела для изображения в шапке. |
| `CatalogHero.build()` | Рисует шапку с заголовком, фотографией и кнопкой перехода к товару. |
| `ProductCard(product: ...)` | Принимает товар для карточки в сетке. |
| `ProductCard.build()` | Показывает фото, название, скидку, рейтинг и цену. Нажатие открывает экран товара. |
| `ProductPage(product: ...)` | Принимает выбранный товар. |
| `ProductPage.open()` | Открывает экран выбранного товара. |
| `ProductPage.build()` | Показывает фото, цены, рейтинг, остаток и описание. На широком экране фото и текст стоят рядом. |
| `ProductImage(url: ...)` | Принимает адрес фотографии. |
| `ProductImage.build()` | Загружает фото по URL и показывает иконку при ошибке. |

### `lib/product.dart` и `lib/product_api.dart`

| Код | Что делает |
| --- | --- |
| `ProductCategory` | Перечисляет четыре раздела. Конструктор задаёт ключ из API и подпись для экрана. |
| `Product(...)` | Хранит данные одного товара, в том числе его раздел. |
| `Product.fromJson()` | Создаёт товар из полей JSON. `toDouble()` принимает и целые, и дробные значения. |
| `Product.salePrice` | Вычисляет цену с учётом скидки. |
| `ProductApi()` | Создаёт объект для запросов к серверу. |
| `ProductApi.getProducts()` | Делает один GET-запрос к `/products`, запрашивает нужные поля и сохраняет товары четырёх выбранных разделов. |

### `lib/product_bloc.dart`

| Код | Что делает |
| --- | --- |
| `ProductEvent` | Общий тип событий каталога. |
| `LoadProducts()` | Запускает загрузку каталога. |
| `SelectCategory(category)` | Передаёт раздел, на который нажал пользователь. |
| `SelectSort(sort)` | Передаёт выбранную сортировку. |
| `ProductStatus` | Перечисляет состояния загрузки, успеха и ошибки. |
| `ProductSort` | Перечисляет виды сортировки. Конструктор задаёт подпись в меню. |
| `ProductState(...)` | Хранит статус, товары, текущий раздел и способ сортировки. |
| `ProductState.visibleProducts` | Отбирает товары текущего раздела и сортирует по цене со скидкой или рейтингу. При равенстве использует название. |
| `ProductBloc(api)` | Связывает события с обработчиками. Переключение раздела и сортировки использует уже загруженные товары. |
| `ProductBloc._loadProducts()` | Вызывает API и выдаёт состояние со списком или ошибкой. |
